上线清单 · personal-site

代码已经在 GitHub 上躺好了（62 个文件）。接下来只剩「接到 Cloudflare」和「绑域名」两件事。

先说清楚分工：Cloudflare 和域名注册商的网页操作需要登录你的账号，我进不去。 这份清单是给你照着点的——每一步都写明了"点什么、填什么、看到什么算成功"。

第 0 步 · 删掉那把 GitHub Token（现在就去）

0
打开 github.com/settings/tokens，把刚才那把 ghp_ 开头的 Token 点 Delete。 顺便把 细粒度 Token 页面里那三把只读的也删掉。
代码已经推完了，这把钥匙再也用不到。留着只是风险。

第 1 步 · 注册 Cloudflare 并连上 GitHub

1
打开 dash.cloudflare.com/sign-up，用你的邮箱注册（免费，不需要信用卡），去邮箱点验证链接。
2
登录后左侧选 Workers & Pages → 点 Create → 选 Pages 标签页 → Connect to Git。
3
这里会让你授权 Cloudflare 读你的 GitHub。选 Only select repositories → 只勾 personal-site → Install & Authorize。
最小授权：只给它这一个仓库的读权限，别的仓库它看不到。

第 2 步 · 配置构建（照抄这张表）

4
选中 personal-site 仓库 → Begin setup，然后按下表填：
字段填什么
Project namepersonal-site（或你喜欢的名字，会变成 xxx.pages.dev）
Production branchmain
Framework presetNext.js (Static HTML Export)
Build commandpnpm build
Build output directoryout
环境变量（可选）NODE_VERSION = 22
最容易填错的两处：输出目录是 out（不是 .next）；构建命令是 pnpm build（不是 npm run build）。 这个站是静态导出的，产物在 out/。
5
点 Save and Deploy，等 1–3 分钟。成功的话会给你一个免费地址： https://personal-site-xxx.pages.dev —— 这时候站就已经在线了，先在手机上打开试试。

第 3 步 · 买域名（还没有的话）

6
推荐 阿里云（支付宝付款、实名方便），买一个 .com，约 ¥75–85/年。
  • 看续费价，别只看首年价（很多后缀首年 ¥9、续费 ¥89）
  • 开 WHOIS 隐私保护（阿里云默认开），否则手机号邮箱会公开
  • 名字优先 你的ID.com，被占了就加 me / dev，别堆一长串数字
  • .cn 要实名认证；只要不把服务器放大陆就不用备案——我们走 Cloudflare，所以不用备案

第 4 步 · 绑定域名（两条路，选一条）

A
把域名托管到 Cloudflare（推荐，全自动）
  • Cloudflare 首页 → Add a site → 输入你的域名 → 选 Free 计划
  • 它会给你两个 NS 地址（形如 xxx.ns.cloudflare.com）
  • 去阿里云域名控制台 → 该域名 → DNS 修改 / 修改 DNS 服务器 → 填那两个 NS → 保存
  • 等 10 分钟到几小时生效（Cloudflare 会发邮件告诉你 Active）
  • 然后回 Pages 项目 → Custom domains → Set up a custom domain → 输入域名 → 一键完成，SSL 自动签发
B
域名留在阿里云，只加解析记录
  • Pages 项目 → Custom domains → 输入域名 → Cloudflare 会告诉你该加什么记录
  • 去阿里云解析控制台，按它给的加一条 CNAME，记录值类似 personal-site-xxx.pages.dev
  • 需要验证时它会给你一条 TXT 记录，照加
  • 缺点：SSL 证书要自己折腾，国内解析也慢一点 → 所以还是推荐 A 方案

第 5 步 · 上线后自检

7
打开你的域名，逐条确认：
  • 地址栏有小锁头（HTTPS 生效）
  • 手机上也打开一次（布局不能崩）
  • 点右上角太阳/月亮能换肤，刷新后还记得
  • 进 /lab，粒子云跟着鼠标转、点阵有涟漪
  • 随便输个不存在的地址，出现404 页面（不是 Cloudflare 的默认错误页）

以后怎么更新

8
改完代码推上去，Cloudflare 会自动重新构建部署，不用管： 
cd C:\dev\personal-site
git add -A
git commit -m "改了点什么"
git -c http.sslBackend=openssl -c http.proxy=http://127.0.0.1:7890 push
注意：项目必须留在 C:\dev\personal-site 这个纯 ASCII 路径。放到含中文的目录里，Next 的构建会直接失败（原因见项目里的 DEVELOPMENT.md）。
